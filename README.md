# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 启动

```bash

cd backend
pip install -r requirements.txt
set DATA_DIR=%CD%\data
set FIXTURES_DIR=%CD%\..\fixtures
uvicorn app.main:app --host 127.0.0.1 --port 10700

# 前端

```

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

## 装载截止闸（分流路径已择一）

**分流路径：装载时按截止分流「旁路 / 正式」。** 装载是唯一的分流决定点，归并开跑前
不做事后剔除（另一条候选路径已弃用，避免两套口径漂移）。

| 事项 | 约定 |
| --- | --- |
| 旁路落库 | **独立旁路表** `sidecar_forward_entries`（不使用流水通道标记列） |
| 分流规则 | 账户级截止优先于全局；`booked_at ≤ C` → 正式待归并；`booked_at > C` → 旁路 |
| 正式归并 | 只扫 `ledger_entries`；旁路键永不可见、永不改余额 |
| 归并失败闭 | 开跑前若发现「旁路待晋升键 ∩ 正式流水键」非空 → 整趟拒绝开跑 |
| 旁路晋升 | 仅显式调用；晋升前**重新校验截止**（仍超截止则拒绝）；失败整笔回滚，不半写入 |
| 截止证明 | `cutoff_proofs` 按装载批次 id 固化「截止时刻 / 正式键 / 旁路键 / 晋升键」，只读 |
| 截止标记刷新 | 每范围至多一行（部分唯一索引）；刷新/下调/上调/清除均留审计，不丢标记、不洗回旁路 |

只读接口：`GET /api/cutoff/proofs/{batch_id}`（按批次 id 查询）、`GET /api/cutoff/proofs`、
`GET /api/ingest-runs`。装载/流水/归并界面均展示通道与证明，数字直接回源旁路表、流水表与证明表。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
